# video_converter

Конвертер видео прямо в браузере: Next.js + TypeScript + FFmpeg (WASM). Файлы не покидают ваше устройство — нет загрузки на сервер и ограничений по размеру.

## Возможности

| Возможность            | Описание                                                                                  |
| ---------------------- | ----------------------------------------------------------------------------------------- |
| Конвертация в браузере | FFmpeg wasm — файл не уходит на сервер                                                    |
| Формат на выходе       | MP4 (H.264) и WebM (VP8)                                                                  |
| Настройки кодирования  | Пресет, качество (CRF), зеркалирование (г/в), удаление метаданных                         |
| Прогресс               | Живой прогресс-бар через callback FFmpeg                                                  |
| Предпросмотр           | Плеер результата + таймлайн с миниатюрами кадров                                          |
| Скачивание             | Кнопка скачивания + размеры входного/выходного файла                                      |
| Платформы              | Многопоточный FFmpeg (`core-mt`) на десктопе, однопоточный fallback (`core`) на мобильных |

## Как это работает

```
Файл пользователя
        ↓
Виртуальная FS (FFmpeg.wasm)
        ↓
ffmpeg.exec(args)
        ↓
output.mp4 / output.webm
        ↓
Blob → File → предпросмотр + скачивание
```

## Архитектура (Feature-Sliced Design)

```
app/          — роуты, layout, настройки COOP/COEP (SharedArrayBuffer)
entities/     — доменные стоны (video, detailsStore)
features/     — фичи: загрузка, конвертация, скачивание, таймлайн
widgets/      — композиционные компоненты (VideoManager, FFmpegStatus, Header)
shared/       — хуки, утилиты, типы, интерфейсы, UI-обёртки
```

> COOP/COEP-заголовки обязательны для `SharedArrayBuffer` (`core-mt`). Настроено в `next.config.ts`.

## Частые проблемы

| Ошибка                             | Причина                       | Решение                                |
| ---------------------------------- | ----------------------------- | -------------------------------------- |
| Конвертация зависает (WebM)        | Слишком низкий CRF для VP8    | Использовать CRF ≥ 32                  |
| Не грузится FFmpeg                 | Нет COOP/COEP для `core-mt`   | Включить cross-origin isolation        |
| «Не удалось загрузить медиаресурс» | RevokeObjectURL активного URL | Чистить только свои URL (frameUrlsRef) |
